Memory vs. State

A fixed-size recurrent state can process a sequence of any length without growing its memory — but it pays by losing the ability to perfectly retrieve any past token on demand.

The Memory Problem

Part 03

BDH — Attention as Synaptic Memory

Dragon Hatchling (BDH) is Pathway's Post-Transformer architecture. It does not treat linear attention as an optimization trick — it makes the state matrix the primary computational fabric, with reasoning and memory sharing the same substrate. BDH-CQ extends this to in-context learning without a backward pass at test time.

Write — Hebbian update (per token)
S ← S + k ⊗ v
For each incoming token, its key vector k is outer-producted with its value vector v. The result is added to the state matrix S. No new slot is allocated — the write distributes information across the shared matrix. This is exactly a Hebbian synaptic weight update.
Normalization accumulator
z ← z + k
A companion vector z accumulates the sum of all stored keys, used to normalize retrieval so outputs stay on a consistent scale.
Read — associative retrieval
o = (S · q) / (z · q)
A query vector q is multiplied against the state matrix. This is equivalent to softmax attention with a linear (identity) kernel — replacing exp(q·k) with q·k. The result: constant-time retrieval from a constant-size memory, at the cost of exact selectivity.

BDH — what changes beyond vanilla linear attention
BDH reports ~5% sparse non-negative activations per token. Rather than every neuron writing to the state on every step, only a small, input-dependent subset fires. This reduces interference: fewer writes per step means each token contaminates the state less.

BDH-CQ further removes the need for evaluation-task demonstrations at training time. Adaptation happens through the recurrent state at inference — no parameter updates, no backward pass. The state is the adapter.

Limitation (stated): BDH's session memory is not equivalent to durable cross-session learning. State capacity is bounded by the matrix size — sufficiently long or dense sequences will still degrade retrieval through interference. This is an open problem in recurrent architecture design.
